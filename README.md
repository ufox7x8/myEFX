第一階段先完成 VST3；未來取得 AAX 開發資格後再接 AAX。

核心產品方向：
- Plugin A / MyEQ：Parametric EQ + Dynamic + Spectral + Transient + Frequency-selective De-noise
- Plugin B：預留 Creative / IR / Reverb
- Plugin C：預留

開發方式：需求、聲音判斷、參考資料由使用者提供；主要 C++ / DSP / GUI / Build / Debug 由 ChatGPT 負責。
