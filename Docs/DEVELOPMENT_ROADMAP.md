# myEFX Development Roadmap

## Stage 0 — Environment
Visual Studio 2022 + CMake + official VST3 SDK

## Stage 1 — Hello Plugin
Compile and load MyEQ.vst3 in VST3 Test Host.

## Stage 2 — EQ Core
Bell / Low Shelf / High Shelf / Frequency / Gain / Q.

## Stage 3 — Dynamic
Per-band threshold / range / attack / release.

## Stage 4 — Spectral
Frequency-selective dynamics inside a band.

## Stage 5 — Transient
Attack / sustain envelope processing.

## Stage 6 — Frequency-selective Transient
Transient shaping constrained by frequency region.

## Stage 7 — De-noise
Noise profile / adaptive estimate / reduction / transient protection.

## Stage 8 — Integration
EQ + Dynamic + Spectral + Transient + De-noise in one band.

## Stage 9 — Productization
Preset, automation, recall, undo, CPU, latency, oversampling, resizeable GUI.

## Stage 10 — AAX
After AAX developer access is available: AAX target, Pro Tools tests, signing/release pipeline.
